# 自定义人物绑定插件

本文件夹可以单独复制或压缩后发送给其他人，不需要外层 MayaAgent 项目。
集成绑定 v1.25.0，身体绑定 v1.4.6，包含原点总控制圆环、连续旋转修复及正方体控制器。总圆环移动、旋转可带动全身，包括 IK 手脚；已有绑定通过面板“添加 / 选择总控制圆环”显式升级。

## 安装与启动

1. 使用 Windows 版 Maya 2024。其他 Maya 版本未验证，当前界面依赖 Maya 2024 自带的 PySide2。
2. 将整个「自定义人物绑定插件」文件夹解压到一个固定位置。不要在压缩包内直接运行。
3. 把本文件夹内的「安装插件.py」拖入 Maya 视口。
4. 安装后会打开集成绑定面板，并在 CustomBodyRig 工具架添加「集成角色绑定」按钮。
5. 以后点击该按钮打开面板。重启 Maya 后也请先打开一次插件，以启用模式切换等交互回调。

安装位置可自行选择，支持中文和空格路径。移动文件夹或更换版本后，请从新位置重新拖入「安装插件.py」，更新工具架路径。运行时需要保留整个文件夹。

普通绑定不需要 Codex、Maya MCP、API Key、Python 环境或联网安装依赖。Maya 自带 Python 与 Qt 即可。

## 创建绑定

- 按部位要求有序选择目标，左键载入、右键设置、中键清空。
- 身体按腰到胸排序；头颈末端为头；手臂按肩、肘、腕；腿按髋、膝、踝、脚趾。
- 默认开启「拷贝动画至控制器」，请检查起止帧与采样间隔。已有约束、驱动或锁定通道仍受保护。
- 同场景不同角色分别使用不同名称前缀，并重新载入各自目标及胸腰、通用根对象。
- 创建前建议另存场景。不要把同一套已经受约束的骨骼重复绑定。

## BIP 动画导入

面板内保留「导入 Max BIP 动画」入口。直接读取 .bip 文件需要本机安装并激活 3ds Max；可以在窗口指定 3dsmaxbatch.exe。插件内已包含后台转换代码，但不包含 Autodesk 软件。
普通角色绑定不需要 3ds Max。连接正在运行的 Max 属于额外桥接功能，本便携包不安装 MCP 服务。详细功能见 BIP_RETARGET_README.md。

## 文件与分发

此文件夹是绑定插件的唯一开发源码目录。后续修改请直接编辑本目录；外层项目的 scripts/package_integrated_rig.py 只校验并压缩这里的文件，不再从旧源码复制覆盖。外层保留的安装脚本是兼容入口，Maya MCP 目录保持独立。

- 安装插件.py：拖入 Maya 安装，工具架以后从这里启动。
- maya_agent/rigs/：全部绑定代码、界面及 JSON / Maya ASCII 模板。
- max_mcp/：BIP 文件转换及可选桥接客户端依赖。
- manifest.json：交付文件清单及 SHA-256 校验值。
- LICENSE：原项目许可文件，请随包保留。

包内没有用户 Maya 场景、动画素材、API Key、MCP 连接凭据或个人配置。不要只发送安装脚本，必须发送整个文件夹。
