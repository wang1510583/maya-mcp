# 动态手指 FK v1.0.0

集成角色绑定的左手、右手分别载入。可以先选各指第一节，再逐层向外选择；按实际父子关系分链，不固定手指数、节数，也允许同手各指节数不同。
所有根节必须直接连接同一个手腕，不允许漏选中间关节、链内分叉或混合两只手。每节生成一个零位 FK 圆环，下节跟随上节；手指组读取原手腕的最终世界矩阵，因此跟随手腕 FK/IK 结果。原骨骼层级、蒙皮和缩放曲线不改动。
集成创建先采集整套原动画，再由代理统一驱动原目标。只有显式 copy_animation=True 才转移 TR 动画并保留备份；与现有模块相同，动画转移保证采样帧，未承诺采样之间完全重合。右键可配置控制器大小、采样范围和间隔。
