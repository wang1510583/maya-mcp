没有身体时胸 / 腰目标回退通用根，均未载入则使用世界空间。没有新建身体时，上述胸 / 腰优先使用相应外部跟随对象；手腕另一空间始终使用通用根 / 世界，不改为外部胸部。`global=0` 保持原空间及动画，`global=1` 跟随另一空间；0–1 混合。双目标权重使用 `1-global` 与 `global`。切换可打帧，但不自动添加无跳变匹配关键帧。需要脚部留在世界原位时，不启用腰部跟随。

## 动画与输入保护

集成 UI 主面板默认勾选「拷贝动画至控制器」，统一设置所有已载入部位；Python API 默认 False。先捕获全部源目标的世界运动，再通过独立代理构建并统一驱动原目标。原 TR 曲线断开并备份，缩放曲线、原父级和蒙皮保留。通用根动画使用独立参考补偿，避免重复运动；之后编辑通用根仍生效。

支持正值等比缩放。开启拷贝动画时允许目标的父级已有 TR / offsetParentMatrix 驱动，例如先建身体再创建腿，父级约束原样保留。所选目标自身的已有约束 / 表达式、动画层、锁定 TR、实例 / 引用、非均匀或负缩放等仍保持原检查。

动画转移仅保证指定范围内采样帧的世界姿态，完成后逐帧比较，最终核对容差默认 1e-4（可调）；异常回滚原连接。不承诺整套缩放时手臂 / 腿求解器仍保持相同比例。

腿部右键设置仍有「进入调整模式」，可在已有普通关键帧 / 已拷贝动画的情况下修改 heel / toe_end / toe 支点，保留原运动。
