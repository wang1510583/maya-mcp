# 手机工程 / 动画互通 1.0.0

集成角色绑定窗口新增“手机工程 / 动画互通…”；也可以把插件根目录的 `安装手机互通.py` 拖入 Maya，生成“手机动画互通”工具架按钮。Python 入口 `maya_agent.rigs.mobile_io.show_ui()`。面板只支持本插件登记的集成绑定，不是任意 Maya 绑定转换器。

## 操作

1. 打开已有 Maya 角色场景。选中一个控制器，点击“刷新 / 识别选择”，或从角色列表选择。
2. “导出”页只有两个主要操作：导出工程和导出动画文件。工程输出 `.mobile.json`；动画输出独立 `.json`，自动使用当前打开角色的身份，不需要指定工程文件。导出仅填写名称，直接上传服务器；不再选择本地路径。未配置联网时提示失败，不报告导出成功。编译和下载使用自动清理的临时文件，曲线恢复备份仍保留。
3. “联网下载”页自动匹配当前角色，选择服务器工程后按角色、版本及快照指纹列出对应动画和保存时间；选择后点击“下载并应用动画”，不需要手动选择工程或动画文件。
4. “动画导入 / 导出”：动画导出只需填写文件名，自动使用当前打开角色的 UUID、绑定版本和快照；联网列表中的“下载并应用动画”会自动下载匹配工程后写入控制器。手动导入旧文件时仍可选择工程和动画，写入角色对应控制器并生成 `maya-animation-backups` 曲线备份。
5. 工程和动画不要求放在同一个本地文件夹；联网时只需位于 Linux 共享目录，服务按文件内身份字段匹配。一个工程可以对应多个动画。
6. “联网下载”页填写服务器 URL 和令牌后可测试连接、刷新共享目录并下载应用已有动画。工程和动画按文件内身份自动匹配；Maya 电脑端继续使用 wang 的 Tailscale MagicDNS 主机名（`http://wang.tail26a65a.ts.net:8765`）；手机端使用固定 HTTPS 反代地址 `https://lempet.top:9000/maya-mobile`，不依赖动态 IPv6。

## 范围与保护

- 新版动画同时保存每整数帧的手机播放采样与完整原始曲线（curvePayloadVersion=1）。未在手机编辑的控制器回传原曲线：各通道的独立关键帧时间、值、切线类型/角度/权重、中间关键帧及曲线延伸模式均保留；无动画通道保持静态，不自动打帧。原曲线完整保存，包含播放范围外的键。手机播放仍用采样插值，未宣称任意 Maya 曲线的子帧播放完全一致。
- 仅支持厘米 / Y 向上及当前离线求解器支持的原生节点。遇到不支持的绑定图会报告错误，不输出半成品工程；不会改建绑定。
- 新导出不覆盖已有同名文件，以免丢失旧手机动画依赖的原始基准。需要更新时使用新文件名。
- 导入核对 UUID、绑定版本、快照 SHA256、控制器登记及锁定/驱动。新建的另一套绑定不能接收旧角色动画。
- 检查不写动画；正式导入前再次检查，并先备份原曲线。不会默默覆盖保存 Maya 文件。
- 手机编辑按控制器轨道记录：添加/粘贴/移动/删除关键帧后，回传该控制器实际保留的关键帧，并使用手机缓入缓出或模式阶梯插值；删除最后一帧会清空对应轨道。未编辑控制器按原曲线恢复。手机时间轴编辑目前使用整数帧；小数帧原曲线只有未编辑时完整保留。支持独立欧拉旋转曲线，不支持动画层或四元数旋转插值。
- 旧版文件缺少完整原曲线时仍走旧兼容导入，不能凭采样可靠还原原来的稀疏键。请用新版重新导出动画；若 Maya 场景本身已被逐帧烘焙，需要先恢复原场景或原曲线备份，不能自动猜测并删除关键帧。
- Linux 服务脚本位于 `server/maya_mobile_exchange_server.py`，默认共享 `/home/wangjiafeng/电脑maya和安卓maya互通文件`，仅接受 `X-Exchange-Token`，并以临时文件原子替换上传内容。服务安装和启动示例见 `server/README.md`。

导出器位于本模块 `backend/`，从 Android 项目的已验证导出模块同步，插件搬家后不依赖开发电脑的安卓目录。更新求解格式时应同步测试 Android 与本模块。服务层 `service.py` 不依赖 UI，可用于自动化验证。

手动上传、刷新、下载应用完成后弹窗报告成功或失败；应用成功以实际导入完成为准。同名服务器上传更新文件。
