# 本草角色绑定 1.0.6

1.0.6 补齐脚掌 `tarsus_L/R1_live_zero`：移动及旋转操作产生的新增位移统一记录到脚腕，保留脚掌旋转和脚趾姿态。普通 S、自动关键帧及动画层一并记录相关变化；已有位移关键帧不自动清零。

1.0.5 修复脚尖支点、脚后跟旋转时留下新增位移的问题：本次旋转产生的位移补偿也记录到脚腕，保持旋转效果。W 拖动超过腿部可达范围后，实际位移数值停止继续向外累积；普通 S 会一起保存脚腕的变化。已有支点位移关键帧保持原样，更新不会自动将旧动画清零；通道栏直接输入仍使用原通道行为。

1.0.4 让脚跟、脚尖、脚掌等实时控制器与脚腕一样跟随实际可达的脚踝位置，避免拖动超过腿部范围时控制器脱离脚部。保留腿部现有拉伸、柔化、支点旋转及动画设置；已有角色无需重建，启用后自动接入。

1.0.3 改进 FK 肘部操作：拖动结束后保持当前姿态，将可等效转换的肘部 Z 偏移吸收到现有大小臂及手腕旋转通道，肘部 Z 不再作为独立残留影响后续小臂操作。数值归零不等于回到初始姿态。按 S 或自动打帧会一起记录必要的配套通道；世界 IK 仍保留独立肘部方向控制。已有整段动画不会在开启助手时自动迁移。

推荐把单文件“本草角色绑定.py”和角色 Maya 文件一起交给动画师。将这个 py 文件拖进 Maya 视口，即可自动安装并打开；不需要解压或另外复制依赖。组件自动存放在 Maya 用户目录的 BencaoRig/runtime 中，安装后移动或删除原始 py 文件不影响工具架启动。重复拖入不会重复创建按钮。

本版修复引用文件后提示 `No object matches name ...rotatePivot` 的问题。控制器按当前引用的命名空间查找；同一角色引用多份时按各自归属操作。无需重建角色或修改引用源文件。更新时先保存工作并重启 Maya，然后拖入新版 py，工具架按钮会更新到新版本。

1.0.2 同时修复引用角色按 S 后切帧归零：已有引用动画会完整复制为当前场景的可编辑曲线，保留已有关键帧及切线，并补齐缺失的时间输入。已有时间映射和锁定通道保持不变，普通 S 键、自动关键帧和动画层继续使用 Maya 自带机制。准备后的动画及连接随你的当前镜头场景保存，引用源文件不会被写回。

手臂拖动中改变的必要联动通道会随普通 S 键一起记录，避免仅记录所选小臂等控制器后切帧偏移。没有操作变化的其他角色不会被打关键帧。

助手自带运行组件，不需要完整绑定制作插件、Codex、网络或另装 Python。也保留以下文件夹版安装方式：

1. 解压整个“本草角色绑定”文件夹，放在固定位置；不要只复制其中一个 Python 文件，也不要在压缩包里运行。
2. 把“安装本草角色绑定.py”拖进 Maya 视口，自动创建“本草绑定”工具架，并添加“本草角色绑定”按钮。重复安装更新原按钮。
3. 窗口只有一个切换按钮：“已开启”表示可以正常操作角色；点击变成“已关闭”，停止操作辅助。首次打开自动开启，之后关闭窗口再打开会保留本次会话的开关状态。
4. 以后每次启动 Maya，点击一次“本草绑定”工具架里的“本草角色绑定”。开启时，本次会话新打开、导入或引用的角色自动接入；关闭窗口不等于关闭功能。

如果先打开了角色文件，再启用助手也可以。助手不重建、不升级、不保存角色，不改动原来的权重或动画。请照常使用 Maya 保存自己的动画工作。

首次启用时，Maya 可能提示加载 `maya_live_edit_undo.py`。这是助手自带的撤销组件；单文件版路径包含 `BencaoRig/runtime`，文件夹版路径位于安装文件夹内，核对后由使用者决定是否允许。拒绝加载时按钮保持“已关闭”，错误显示在 Maya 脚本编辑器，不会添加额外界面说明。无需关闭 Maya 的安全检查。

保留：实时旋转与移动校正、脚部位移统一、FK / IK 与各部位空间切换、原有模式面板操作、动画层及关键帧辅助、临时原生约束入口、撤销重做。

不提供：创建绑定面板、手机工程导入导出、BIP 转换、制作端修复工具。部分底层模块由制作端和运行端共用，随包保留以避免遗漏依赖，不在助手界面提供制作入口。

适用环境：Windows Maya 2024，配套集成绑定核心 v1.26.26。其他 Maya 版本暂未验证。后续制作端新增操作功能时，应一起更新本助手。角色文件中的制作版本号不一定随着修复更新。

常见问题：

- 姿态正确但旋转方向不对：确认本次启动 Maya 后已启用助手。
- 提示已加载另一版本：保存工作并重启 Maya，然后使用同一份最新助手，不要在会话中混用不同版本。
- 移动了助手文件夹：重启 Maya，再从新位置拖入安装文件，更新工具架路径。
- 卸载：关闭 Maya，删除助手文件夹（单文件版为 Maya 用户目录下的 BencaoRig）及“本草绑定”工具架即可。安装不修改 userSetup、不向角色注入启动脚本、不要求允许未知场景脚本。
