# 自定义腿部系统 v1.1.0

从用户的腿部参考场景提取并复刻 62 个原生节点，保留两段柔化伸缩求解、脚跟/脚尖/脚趾控制和 Easy Rig 的三个登记节点。运行只读取包内 `data/leg_v1.ma` 和 `leg_v1.json`，不依赖原插件、原场景或 outputs；不导入源文件，不包含脚本节点、渲染配置或场景回调。

将项目根目录 `install_custom_leg_rig.py` 拖入 Maya，工具架出现「腿部系统」。身体、手臂、腿部窗口使用 `maya_agent.rigs.ui_common` 的统一窗口、选择列表、动画设置、按钮和提示样式。三个绑定模块保持独立。

## 使用

1. 打开窗口，按 **髋 → 膝 → 踝 → 脚趾** 依次选择恰好四个骨骼或物体。
2. 检查选择顺序、名称前缀；需要右腿时勾选 **R 右侧腿部**。
3. 默认勾选「驱动所选骨骼 / 物体」。原父子关系、蒙皮、姿态保留，不重新蒙皮。
4. 有动画时明确勾选「拷贝动画至控制器」，设置起止帧和采样间隔，再创建。

只能从四个选择目标创建，UI 和 MCP 均没有固定模板生成选项。`_build_template()` 是模块内部组装及测试入口，`build()` 与 `build_from_selection()` 均执行四点创建。

```python
from maya_agent.rigs.soft_leg import build_from_selection, set_adjustment_mode, show_ui
show_ui()
rig = build_from_selection(targets=['|hip','|knee','|ankle','|toe'], side='R')
set_adjustment_mode(rig, True)
# 移动返回的 heel / toe_end / toe 黄色 guide
set_adjustment_mode(rig, False)  # 应用并锁定
```

R 选项按所选目标的位置创建，仅改变本套系统的侧别命名，不自动空间镜像。默认 L；多套共存，各自独立命名空间。通过返回值 `controls`、`target_mapping` 查找节点，不硬编码侧别。

## 调整模式

在「调整已有系统」选择一套系统，或选择其控制器后「载入选中的腿部系统」。勾选「进入调整模式」，通过三个按钮选择黄色支点标记，用 W 移动。取消勾选会将位置应用到 heel、toe_end、toe 的旋转/缩放轴心以及定位器外观，并隐藏、锁定标记。支持反复进入和「取消本轮调整」。关闭窗口不自动应用；状态存在场景根组中，重新打开可继续。

原控制器的普通动画通道仍可使用；锁定的是设置支点编辑，不是禁止控制器运动。移动 guide 不驱动骨骼；提交使用保留变换矩阵的轴心编辑，验证姿态未变化，失败恢复轴心数据。此功能只接受本模块创建的系统，不修改源参考系统。

v1.1.0 支持已有普通关键帧和已转移的动画，也可用于本插件 v1.0.0 创建的系统，无需重建。应用支点时自动添加独立的原生动画补偿节点，保留原运动和原关键帧、切线、外推；之后编辑旋转会使用新支点。无需设置采样区间，也不将现有动画重烘焙成逐帧关键帧。

补偿使用调整前旋转/缩放曲线的独立快照，比较旧/新轴心参考变换的局部位移差，接到控制器 `rotatePivotTranslate`。参考图不反读控制器的实时旋转，因此不会抵消后续动画修改。数学补偿在连续时间上求值，支持分数帧、循环、反复调整和保存场景后继续使用，不需要回调或插件驻留。每轮调整按关闭模式时的帧解释 guide 世界位置；补偿节点和旧参考曲线随场景保留。

支点调整接受普通时间驱动的旋转/缩放曲线以及本工具已有的支点补偿。直接给支点属性设置动画，或旋转/缩放由动画层、表达式、约束等外部图驱动时，仍会说明具体不支持的通道并保留原状态；这与「有关键帧不能调整」的旧限制不同。设置支点仍是一次绑定设置修改，不是打帧切换支点功能。

## 动画转移

与手臂系统一致：临时定位器先捕获所有采样帧世界变换；原 TR 曲线断开并备份到 `sourceAnimationBackup`，再由新输出约束驱动目标。烘焙髋部平移、膝盖方向、脚部/脚趾 TR 和两段长度。四个控制器的 `animationOffset` 补偿通道保留独立目标朝向和位移。输出最终世界矩阵在每个采样帧核对，容差 1e-4；失败恢复原连接，成功删除临时采样与解算节点。

普通正值等比缩放动画保留在目标/父级；不支持动画层、已有约束/表达式/驱动、锁定 TR、引用/实例、非均匀或负缩放、剪切及轴心/轴向动画。只保证范围内采样帧姿态；烘焙使用线性切线，采样之间或区间外轨迹不作保证。原曲线节点、原关键帧与切线保留备份。

要求厘米、度、Y 轴向上。拒绝重合关节和髋踝完全折叠；共线髋膝踝自动选择默认弯曲方向，可移动膝盖控制器调整。支点默认投影到 Y=0 地面，可通过调整模式修改。整体缩放父组不是本版本支持范围。原数学表达式未替换，仍有原求解器的极端参数边界。

## 模块

- `selection.py`：四点检查、几何匹配、约束和回滚。
- `animation.py`：世界动画采样、控制器烘焙与补偿输出，复用身体/手臂的捕获和回滚框架。
- `adjustment.py`：持久设置模式、guide 锁定及轴心编辑。
- `pivot_animation.py`：保存原动画曲线快照、连续时间的支点补偿及失败恢复。
- `ui.py`：与身体/手臂统一布局的 Maya 窗口。
- `data/`：SHA256 校验的版本化原生节点模板、可读求解表达式及参考矩阵。
- `maya_agent.tools.custom_leg_rig`：`create_custom_leg_rig`、`set_leg_adjustment_mode`。

创建/模式编辑支持撤销重做；不自动保存场景。失败清理先移除本套约束，避免连带删除原目标；释放备份 message 连接后才能删除失败的图。

回归：`scripts/test_leg_animated_pivots_live.py` 覆盖关键帧/分数帧/循环、旋转顺序、缩放、重复调整、后续旋转、取消和失败恢复；`scripts/test_custom_leg_animation_live.py` 覆盖拷贝动画后的 L/R、骨骼蒙皮及父级缩放；`scripts/test_custom_leg_ui_mcp.py --animation` 覆盖 UI 和跨请求撤销重做后的动画一致性。
