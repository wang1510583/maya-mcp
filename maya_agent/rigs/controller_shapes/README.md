# 控制器外观模板 v1.0.1

v1.0.1 以用户再次修改后的左肩、左臂、左腿外观为准，同步右侧颜色、尺寸与镜像形状。形状按左右控制器的局部轴转换；右侧的轴心、变换、动画和约束保持原样。模板保留新的左右参考尺寸，之后仍按所选目标比例缩放。重新采集时跳过 lodVisibility 关闭的旧求解形状，防止重复生成或显示隐藏辅助形状。

显式作者工具 `scripts/sync_controller_style_live.py` 可对局部轴对称、同拓扑的左右控制器执行同步，并备份模板与外观数据；周期球形曲线整体写入，避免逐点编辑接缝产生变形。正常创建不依赖该脚本。

从用户修改后的角色提取 30 个控制器，保存为 `data/controller_shapes_v1.json`。包含身体 4 个、头颈 2 个、双肩 2 个、双臂 8 个、双腿 14 个。只读包内数据，运行时不依赖参考 Maya 文件或 outputs。

模板保留曲线 CV、次数、周期形式、节点和形状颜色、隐藏定位器及关节 drawStyle。内部参数、扭转与末端辅助控制器继续使用原求解模板和显示层规则。源码固定手臂复刻入口 `soft_limb.build()` 保留原始技术模板；按选择创建的独立窗口与集成面板使用新外观。

尺寸使用目标世界空间的相邻骨骼距离：身体 / 头颈按链总长，手臂 FK 按对应臂段长度，肘控制器按全臂长，膝 / 髋按大腿加小腿长，脚部按踝到脚趾的长度。肩膀优先按锁骨到子骨骼长度，再按父级距离 / 物体包围盒估算；孤立空变换没有长度信息时按世界缩放倍率。头颈和肩膀仍叠加现有 `control_size` 设置。

使用的是骨架比例适配，不根据不同角色的胖瘦自动包裹网格表面。相同骨架尺寸而体宽不同的模型仍可编辑曲线 CV。取创建帧的长度作为固定尺寸，不在播放时动态缩放控制器；弯曲和位移不会改变链长，已有拉伸会影响创建帧测得的尺寸。

曲线坐标以旋转支点为基准，并补偿控制器的世界缩放。只添加显示形状、调整显示属性，不改变控制器 TRS、轴心、动画、约束或蒙皮。原形状可能向求解器提供 worldPosition，因此保留并关闭其 lodVisibility。新曲线使用 cmds 创建，支持撤销。腿部调整模式只移动带 `controllerArtwork` 标记的曲线，保留手调外观偏移；失败时恢复 CV。

身体和颈部数量变化时按链上的顺序选取参考形状，身体两端保留腰胸外观，中间形状按归一化次序映射。支持已有的 2–64 个目标。

显式更新模板可在 Maya 中调用 `capture(rig, path)`，其中 rig 是集成返回值或从根节点 `integratedRigData` 读取的字典。该操作只读取当前场景并写入 JSON；不会自动更新模板，也不会修改旧绑定。`apply()` 是新建流程内部入口，不用于批量修改旧绑定。

回归：`scripts/test_controller_shapes_live.py` 在当前场景内使用独立临时目标，比较原参考 CV 与半倍 / 原大 / 双倍尺寸结果，检查动画拷贝及带动画的左右脚支点调整。还验证身体 2 / 8 节及左右臂连续 10 次 Easy Rig 对齐。
