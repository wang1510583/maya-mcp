# 集成角色绑定 v1.6.2

将项目根目录 `install_integrated_rig.py` 拖入 Maya 2024，工具架 `CustomBodyRig` 会增加「集成角色绑定」。整合身体、头颈、肩膀、手臂和腿部；原独立工具继续可用。不依赖参考脚本、Easy Rig、AI API 或 outputs。

v1.4.4 加固腿部右键设置的系统列表刷新：忽略已关闭窗口的旧回调，列表重建期间暂停模式同步，按序号选择系统，避免失效或空菜单的项目查找警告。

v1.6.2 使用腿部 v1.1.2：预先读取原目标的蒙皮绑定脚底参考，并传给内部代理创建，避免代理丢失蒙皮信息。脚跟、脚尖、脚趾位于同一脚底参考面并随脚腕姿态变化，不使用斜骨骼连线。无蒙皮时退回脚趾高度平面估算。

## 面板布局

顶部三列为“载入根 / 载入胸 / 载入腰”，第二行显示载入状态及对象名，长名称悬停查看完整路径。通用根不再提供单独的“清除根”按钮，统一中键清空。

部位按钮为三行三列：右肩膀 / 头脖子 / 左肩膀；右手臂 / 身体 / 左手臂；右腿 / 开始创建 / 左腿。左键载入、右键设置、中键清空保持不变。

## 参考场景的部位层级

v1.4.0 按用户新参考场景设置控制关系：部位总组分开，肩膀控制器零组挂在胸部下；肩膀通过定位器及点约束带动对应上臂起点；腰部只带动腿部髋起点，脚部 IK 不挂在腰部下。移动身体不会拖动整条腿的脚部 IK。未载入肩膀时，手臂起点回退胸部；没有新建身体时，v1.6.0 可通过外部胸部 / 腰部跟随对象建立相同的起点关联。连线开关不恢复。

头颈改用独立 `head_neck` 模块：头部 locator 控制器独立旋转，颈部 joint 控制器的父组混合胸与头的方向，单颈各影响一半；头的位置跟随颈骨链。详见 `../head_neck/README.md`。头部额外平移使用 `positionOffsetX/Y/Z`。

v1.4.1 修正头颈运动：颈根与头的位置通过父级下的锚点跟随旋转，不使用固定的点约束偏移；头颈控制器统一朝向，输出偏移保留原骨骼轴向。转胸、转脖子及转头的组合行为已与当前参考结构逐项对比。

手臂内部仍保留参考的 FK / IK 输入链。肩膀移动会影响上臂起点及其 FK 子链；需要手腕使用世界 / 通用根空间时，在右键开启手腕多空间并设置 `global=1`。

- **左键部位按钮**：载入当前有序选择，显示已载入数量。
- **右键部位按钮**：设置动画范围、拷贝动画、多空间等；左右由主面板确定。
- **中键部位按钮**：清空载入，保留详细设置和场景。通用根按钮也支持中键清空。
- **载入通用根骨骼 / 控制器**：可选。载入后所有部位共享整体根运动，部位起点关联仍保留；移动通用根仍会整体移动部位，包括 IK 手脚。未载入时各部位放在装配总组下。
- **载入胸部跟随对象**：没有新建身体时，选择现有胸骨（例如 `spine_03`）左键载入，供肩膀、手臂起点和头颈跟随；不把整条手臂挂在胸部下。
- **载入腰部跟随对象**：没有新建身体时，选择现有腰骨（例如 `pelvis`）左键载入，只带动髋起点，脚 IK 在 `global=0` 时保持独立。
- 两个跟随按钮均显示载入状态、支持中键清空，并用 UUID 追踪重命名。创建身体时优先用新建胸腰控制器，忽略这两个外部对象。不要把胸腰跟随对象填入通用根；通用根只用于人物整体移动，可留空。
- **开始创建**：仅创建已载入部位，空部位跳过。重复创建使用独立命名空间，一次 Ctrl+Z 撤销整次创建。

| 部位 | 载入顺序 / 数量 |
| --- | --- |
| 身体 | 腰 → 胸，2–64 个 |
| 头脖子 | 颈根 → 其余颈骨 → 头，2–64 个，独立头颈模块 |
| 左 / 右肩膀 | 每侧 1 根锁骨或物体 |
| 左 / 右手臂 | 上臂根 → 肘 → 腕，3 个 |
| 左 / 右腿 | 髋 → 膝 → 踝 → 脚趾，4 个 |

肩膀目标不能与上臂目标重复。按输入位置创建，不自动镜像。UI 以 UUID 追踪目标，重命名或修改父级后仍可解析；删除目标需要重新载入。身体、手臂、腿原有动画、对齐及腿部支点调整功能保留。部位关联使用冻结的原运动参考，既保留拷贝动画，又允许后续控制器编辑生效；不能把实时控制器反接作其自身运动补偿。

身体不再附带 `layer1/2/3` 分类层，颜色改为直接显示覆盖；整套绑定仅保留有实际隐藏用途的 `NoDisplay` 层。

## 辅助物体显示层

v1.5.0 创建后自动建立本套命名空间下的 `NoDisplay` 层并关闭可见性。收纳 `strech_ik_foot*` / `strech_ik_knee*`、内部 `knee_ctrl*`、手腕 `hand_L/R1` 末端辅助定位器、`ik_connect_L/R1`、肩髋连接定位器、输出代理及扭转辅助曲线 / locator 形状。同时关闭 `base_L/R*` 骨骼的局部轴显示。

保留 FK、肘部方向、脚腕、脚跟 / 脚尖 / 脚趾、Knee 膝盖、身体、头颈与肩膀主控制器。只改变显示，不改动画或求解连接；不隐藏角色模型 / 源骨架，不修改 FK 控制器形状。参数节点仍可通过大纲选择调整。

显示层使用绑定根的 UUID 标记所有权；重复整理复用本套层，同名非本工具层保留，其他显示层不删除。在 Layer Editor 打开该层的 V 可显示本次收纳的辅助图形（原本已单独隐藏的节点仍保持原状态）。模块 `integrated.display.apply(rig)` 可用于整理已创建系统，返回信息记录在 `integratedRigData.display`。

## 可选多空间

集成面板中所有已有多空间选项默认勾选，可在右键设置中单独取消；无需先打开设置，开始创建也会使用这些默认值。Python API 仍需显式启用 `space_*`。控制器属性显示名称统一为 `global`，不附中文注释；默认值仍为 0。它与部位起点关联是独立功能。

| 设置位置 | 控制器 | 另一空间 |
| --- | --- | --- |
| 头脖子 | 头控制器（只切换方向） | 身体胸部 |
| 身体 | 胸部控制器 | 身体腰部 |
| 手臂 | 上臂 FK 控制器 | 身体胸部 |
| 手臂 | 手腕 FK 控制器 | 通用根；未载入则世界 |
| 腿 | foot 脚部 IK 控制器 | 身体腰部 |
| 腿 | Knee 膝盖控制器 | 同侧 foot 脚腕控制器 |

v1.4.3 新增 `space_knee`。左右腿右键的「膝盖多空间 → 同侧脚腕」默认勾选，可独立于脚部多空间取消。`Knee_L/R.global=0` 保持原空间，`=1` 跟随本腿 `foot_L/R1` 的平移和旋转；目标不是腰部，也不会连接另一条腿。

没有身体时胸 / 腰目标回退通用根，均未载入则使用世界空间。没有新建身体时，上述胸 / 腰优先使用相应外部跟随对象；手腕另一空间始终使用通用根 / 世界，不改为外部胸部。`global=0` 保持原空间及动画，`global=1` 跟随另一空间；0–1 混合。双目标权重使用 `1-global` 与 `global`。切换可打帧，但不自动添加无跳变匹配关键帧。需要脚部留在世界原位时，不启用腰部跟随。

## 动画与输入保护

集成 UI 所有部位默认勾选「拷贝动画至控制器」，可单独取消；Python API 默认 False。先捕获全部源目标的世界运动，再通过独立代理构建并统一驱动原目标。原 TR 曲线断开并备份，缩放曲线、原父级和蒙皮保留。通用根动画使用独立参考补偿，避免重复运动；之后编辑通用根仍生效。

支持正值等比缩放。开启拷贝动画时允许目标的父级已有 TR / offsetParentMatrix 驱动，例如先建身体再创建腿，父级约束原样保留。所选目标自身的已有约束 / 表达式、动画层、锁定 TR、实例 / 引用、非均匀或负缩放等仍保持原检查。

动画转移仅保证指定范围内采样帧的世界姿态，完成后逐帧比较，容差 1e-4；异常回滚原连接。不承诺整套缩放时手臂 / 腿求解器仍保持相同比例。

腿部右键设置仍有「进入调整模式」，可在已有普通关键帧 / 已拷贝动画的情况下修改 heel / toe_end / toe 支点，保留原运动。

## Python / MCP

```python
from maya_agent.rigs.integrated import show_ui, build
show_ui()
rig = build({
    'body': {'targets': body_targets},
    'shoulder_L': {'targets': [clavicle_target]},
    'arm_L': {'targets': arm_targets},
}, namespace='hero', chest_follow='spine_03', hips_follow='pelvis')
```

`targets` 使用有序完整路径。可选 `general_root='main_ctrl'`、`chest_follow='spine_03'`、`hips_follow='pelvis'`；部位选项包括 `name`、`drive_targets`（默认 True）、`copy_animation`（默认 False）、`start_frame`、`end_frame`、`sample_step`、肩膀 `control_size` 和 `space_*`。

旧配置的 `connected` 参数保留兼容读取，不再控制整组挂接。结果 `connected=False` 表示没有整组挂在身体；新的起点与控制器关联记录在 `hierarchy`，通用根跟随记录在 `general_root_connected`。返回 parts、spaces、general_root、space_root、原曲线备份及误差，装配根 `integratedRigData` 保存元数据。打开新版 UI 不自动替换旧场景已有绑定；后续新建使用本结构。

回归脚本：`scripts/test_reference_hierarchy_live.py` 验证静态 / 动画、八部位、肩髋起点关联、头颈混合、脚部 IK 世界固定、多空间、通用根及连续对齐；`scripts/test_reference_character_copy_live.py` 使用当前参考角色姿态的临时副本验证全身动画交接，不修改参考绑定。

外部跟随回归：`scripts/test_external_follow_live.py`，覆盖左右手腿、带 / 不带肩膀、头颈、普通动画拷贝、通用根共存、胸腰旋转后手脚独立及循环输入拒绝。新版本不自动迁移已有系统。
